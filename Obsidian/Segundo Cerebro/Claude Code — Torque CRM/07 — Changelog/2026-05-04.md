## Decisoes
- Meetings como entidade separada (nao estender follow_ups) — semanticas diferentes (time-blocked vs task)
- Google Calendar como overlay readonly (nao source of truth) — independencia de integracao externa
- RPC UNION ALL (nao views materializadas) — simplicidade, sem refresh strategy
- API key auth no webhook (nao JWT) — consumidores externos (n8n, cal.com) nao tem JWT Supabase
