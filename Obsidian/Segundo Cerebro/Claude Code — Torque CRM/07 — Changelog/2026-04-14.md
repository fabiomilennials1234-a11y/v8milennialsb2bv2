### Padrões técnicos estabelecidos

- **`vi.resetModules()` + dynamic `await import()`** — para módulos com env captured at top-level (google-calendar-utils, tinyerp-utils, asaas, natural-messaging).
- **Helper `scripted()` supabase mock** — em `lead-service-branches.test.ts`, permite injetar responses step-by-step incluindo erros. Reutilizável.
- **Mock `serve` + `withSentry` + `createClient`** — padrão pra testar edge functions completas (`lead-webhook/index.ts`).
- **Hoisted `mockState` + refactor de createClient mock** — em `shared-user-auth.test.ts`, para tornar happy paths testáveis.
- **Real Node `crypto.createHmac`** via vitest alias — descoberta: `vi.mock` na URL Deno é inerte pois o alias resolve primeiro.
- **Web Crypto API real** pra SHA-256 (em `shared-auth-branches.test.ts` pra hash de API keys).
- **Chunked base64 testado** — `embeddings.generateMultimodalEmbedding` com buffer de 100KB força o loop `String.fromCharCode(...subarray(i, i+32768))` evitando stack overflow.
