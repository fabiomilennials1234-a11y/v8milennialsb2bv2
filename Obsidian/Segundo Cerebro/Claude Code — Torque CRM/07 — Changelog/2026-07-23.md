## Decisões
- Catálogo = **tabelas read-only FK-enforced** (não função-literal) → ID inválido vira FK violation na escrita. Ver [[ADR-0023]].
- Presets de razão (conversão/comparecimento/ticket médio) **semeados no catálogo** (`metric_catalog_ratios`), não só-UI — descobríveis via `fn_metric_catalog`, testados em pgTAP.
- Rascunho+publicar: `dashboard_pages.draft jsonb` (staging) + `dashboard_widgets` publicado; `fn_publish_dashboard_page` faz swap atômico (widget inválido reverte tudo, parede anterior sobrevive). Contrato acordado com Vitral.
- Permissão: admin/owner + master montam; membro só lê (RLS de escrita admin-only, padrão money-guard).
- Flag de rollout segue precedente `organizations.send_governor_*_enabled` (coluna booleana por-org, default OFF).
