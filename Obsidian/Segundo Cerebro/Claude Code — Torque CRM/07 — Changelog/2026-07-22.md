## Decisões (revisão do revisor)
- Pre-dedupe do merge = DATA-DRIVEN via catálogo (não lista estática) — o schema cresceu 7 tabelas com UNIQUE(lead_id …) além das 8 originais (incl. pipeline_entries → colisão garantida no caso comum, merge abortava). Descoberta dinâmica previne recorrência.
- Match por nome = operador `%` (indexável) + índice GIN trgm, não `similarity()>=0.6` (nested-loop N² estourava timeout na maior org, 3906 leads).
- `find` recebe org explícita validada (scoping correto p/ master/multi-org, reduz blast-radius de perf).
