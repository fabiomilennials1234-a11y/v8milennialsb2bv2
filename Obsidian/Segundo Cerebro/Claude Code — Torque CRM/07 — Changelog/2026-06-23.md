## Decisões

- **Sync via trigger + edge fn interna** (não no hook frontend, nem retrofitando `google-calendar-events`): robusto a qualquer caminho de escrita; separa superfície sistema vs usuário; não arrisca a função que a UI usa.
- **Helpers de evento em arquivo novo** (`google-calendar-events-api.ts`): evita o gate de cobertura per-file 100% de `google-calendar-utils.ts`.
- **Descoberta**: o trigger de sync de leads (`trg_leads_google_calendar_sync`) chama `google-calendar-events` com service key como Bearer → `authenticateUser()` 401 → provavelmente quebrado. Documentado como dívida; não corrigido nesta entrega (fora de escopo).
