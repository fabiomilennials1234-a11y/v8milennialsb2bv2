# MOC - Features

**Resumo**: Mapa de todas as features do Torque CRM organizadas por dominio funcional.

## Jornada de Vendas (Pipeline Estrutural)

O lead percorre 3 pipes estruturais em sequencia:

1. [[Pipe WhatsApp]] - Qualificacao (novo → abordado → respondeu → agendado)
2. [[Pipe Confirmacao]] - Confirmacao de reuniao (D-5 → D-1 → compareceu)
3. [[Pipe Propostas]] - Propostas comerciais (proposta → vendido/perdido)
4. [[Upsell]] - Pos-venda e cross-sell

Alem dos pipes estruturais:
- [[Funis Hub]] - Dashboard central de todos os funis
- [[Pipelines Customizados]] - Funis permanentes e temporarios por org

## Comunicacao

- [[Chat WhatsApp]] - Interface unificada multi-canal
- [[Mensagens Agendadas]] - Envio programado via cron
- [[Templates de Mensagem]] - Templates com variaveis e slash commands

## Automacao

- [[Workflow Builder]] - Editor visual DAG (29+ triggers, 25+ actions)
- [[Campanhas]] - Campanhas temporarias com metas e gamificacao
- [[Regras de Pipe]] - Dispatch automatico por stage
- [[Follow-ups]] - Tarefas auto-geradas e manuais

## Inteligencia Artificial

- [[Copilot]] - Agentes IA conversacionais (qualificador, SDR, agendador)
- [[Oraculo Comercial]] - Coaching IA e forecasting
- [[Lead Score]] - Score automatico 0-100 via IA

## Analytics

- [[Dashboard]] - Dashboard principal (4 tabs)
- [[Dashboard Outbound]] - Dashboard simplificado outbound
- [[Analytics Comercial]] - Analytics avancado (master only)
- [[Analytics UTMs]] - Explorer hierarquico de UTMs
- [[Performance]] - Ranking + Metas + Premiacoes
- [[Ranking]] - Leaderboard realtime
- [[TV Dashboard]] - Dashboard fullscreen para TV

## Equipe

- [[Gestao de Time]] - CRUD membros, roles, seats, invite
- [[Comissoes]] - Comissoes por venda
- [[Metas]] - Goals mensais time/individual
- [[Premiacoes]] - Awards e badges com gamificacao

## Integracoes

- [[WhatsApp Evolution]] - Evolution API (multi-device)
- [[Meta Facebook]] - Meta Ads + Messenger + Instagram
- [[Google Calendar]] - Sync calendario
- [[TinyERP]] - Sync produtos, pedidos, NFe
- [[Asaas Pagamentos]] - PIX, card, subscriptions
- [[SZ Chat]] - SZ.Chat Alamaster
- [[n8n Orquestracao]] - 20+ workflows de ingestao

## Admin

- [[Onboarding]] - Wizard 6 steps para novas orgs
- [[Configuracoes]] - Hub de config (8+ tabs)
- [[Permissoes Sistema]] - RBAC 4 camadas
- [[Checkout e Planos]] - Wizard de checkout
- [[API Docs]] - Documentacao interativa
- [[Webhooks]] - Webhooks outgoing com retry
- [[Master Admin]] - Super-panel (master only)
