# Torque CRM — Design System

Harness visual isolado para os componentes do Torque CRM.

## Como rodar

```bash
npm run storybook
# http://localhost:6006
```

## Convenções

### Fixtures estáticas
Toda fixture de dados em stories vive em `src/mocks/chat-fixtures.ts`. **Zero chamadas a Supabase** nas stories. Dados de hook injetados via `queryClient.setQueryData` no decorator da story.

### Sem mock de rede
Stories não usam MSW. Se um componente tem dependência obrigatória de rede, crie um subcomponente `*View` puro ou injete via `setQueryData`.

### Dark mode
Preview configurado em dark mode por default — token `hsl(30 15% 10%)` como background. Alterne via painel "Backgrounds" se precisar verificar light mode.

### Acessibilidade
Addon `a11y` ativo em todas as stories. Verifique o painel "Accessibility" antes de mergear componente novo.

## O que não é

- Não é teste de integração — não testa fluxos completos com backend
- Não é substituto de E2E — não testa navegação ou estado global
- Não é fonte de verdade de negócio — isso é `src/hooks/` + `supabase/`
