## Acceptance criteria

- [x] E2E real cobre jornada principal, teclado, grupos recolhidos, resumo, erros no campo e publicação versionada.

- [x] Medir volume representativo e fixar limites de consultas, período, expressões e timeout no servidor e UI.
- [x] Históricos grandes não são carregados integralmente; truncamento não vira ausência.
- [x] Critérios de produtos/atividades com decisão pendente não são declarados entregues; lacunas são resolvidas antes de certificar escopo completo.
- [x] Tempo comercial permanece segunda entrega; liberação em produção exige autorização específica.
- [x] Este ticket integra evidências; não substitui testes obrigatórios de cada fatia.
